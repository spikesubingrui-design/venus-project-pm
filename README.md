# Venus Project PM

让团队进度落到可验收的上线节点。

面向幼儿园 / ERP 项目的 **Agent Skill 总控流程**：连接项目计划、飞书日报、任务表、动态成员名单与晨晚追踪。

## 管理什么

- 模块里程碑与责任人。
- 当前上线阶段、下一节点和延期阻塞。
- 需要项目负责人介入的事项。

[Venus Tracker](https://github.com/spikesubingrui-design/venus-tracker) 负责数据同步与追踪，本仓库负责流程和项目经理判断。

## 使用

```sh
git clone https://github.com/spikesubingrui-design/venus-project-pm.git
```

先阅读 SKILL.md。本仓库 **不包含** 引用的业务同步脚本、飞书应用、Base、roster、planning 文件或定时运行环境。它不是独立项目管理软件；安装者需要替换原文中的个人路径，并自行准备和验证依赖。

## 视频演示建议

以合成项目展示“模块完成”如何映射到测试、注册、提审、上线节点；真实飞书账号写入、催报和送达须另行验证。
